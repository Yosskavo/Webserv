Description

This project is aimed to create a simple HTTP/1.0 and HTTP/1.1 web server in C++98.

It supports GET, POST, and DELETE methods, directory indexing, custom error handling, cookie/session management, and multi-language CGI execution.

Post & File Management

Upload files directly to the server via HTTP POST. You can view uploaded files or delete them using HTTP DELETE.

Max Body Size Limit: 10 KB (Uploads exceeding 10 KB will be rejected with a 413 Payload Too Large error).
